# Referensi resmi GrowKaz Stickman (salinan dari plugin)

Diekstrak dari `plugin/GrowKaz_Stickman.plugin` (skill `make-2d-video`, v0.1.0, penulis GrowKaz). Ini panduan asli di balik tampilan engine `studio/`.
- `style-bible.md`: **tampilan** (tokoh, set, cahaya, kamera, kosakata shot, transisi, grafik, aturan 9:16, daftar larangan). Baca seluruhnya sebelum merancang shot.
- `story-breakdown.md`: menulis bible dan shot list, aturan tempo (median 2–3,5 dtk, 15–25 shot/menit).
- `engine-api.md`: API adegan, skema config/shots.json, three-kit.
- `sound-design.md`: musik, SFX, ambience, level suara.
- `render-qc.md`: preview, render, checklist QC, pemecahan masalah.

Ringkasan untuk RAKA dan pemetaan ke formula channel: `brand/gaya-growkaz.md`. Jangan edit salinan ini; ubah aturan RAKA di `brand/gaya-growkaz.md`.
