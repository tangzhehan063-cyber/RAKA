Workflow cepat (detail di WORKFLOW.md)

  1. Awal sesiBaca STATUS.md, git fetch + merge cabang claude/* yang belum masuk. Container baru: tools/produksi.sh setup.
  2. Ide3–4 pencarian TikTok paralel (trim) → scrape_ringkas.py → 10 ide + 1 rekomendasi.
  3. Naskah1 WebSearch cek fakta → naskah/<slug>.md → tunggu ACC.
  4. Setelah ACCKomentar 2 video + caption + TTS Ghaisan dalam satu giliran.
  5. Timelineproduksi.sh init → Scribe → produksi.sh timeline.
  6. AdeganTulis shots.tsv + kode shot (contekan API di WORKFLOW.md) → produksi.sh shots.
  7. Rendersheet sekali → stills untuk perbaikan → final di background (render+mix+QC).
  8. Selesaiproduksi.sh cover → update STATUS + arsip + republish artifact ini → commit/push → kirim file.

Hemat token: tidak membaca JSON mentah, 1 contact sheet per cek, render penuh di background, shot list ditulis sebagai TSV ringkas.
