Aset reusable untuk video baru. Setelah `python3 tools/new_project.py ...`:
`cp studio/library/cast.js studio/projects/<slug>/scenes/ && cp studio/library/sets/*.js studio/projects/<slug>/scenes/sets/`
Set `kamar.js` (jam 03:00, meja+lampu, kertas ketakutan, bayangan Si Ramalan; butuh `RAMALAN_INK` di cast.js) dari video 2. Contoh shot lengkap (kamar hujan, papan blueprint, kalender, 3D, jatuh-bangkit): `studio/projects/hari-ke-10-shorts/scenes/shots/`.
