Aset reusable untuk video baru. Setelah `python3 tools/new_project.py ...`:
`cp studio/library/cast.js studio/projects/<slug>/scenes/ && cp studio/library/sets/*.js studio/projects/<slug>/scenes/sets/`
Contoh shot lengkap (kamar hujan, papan blueprint, kalender, 3D, jatuh-bangkit): `studio/projects/hari-ke-10-shorts/scenes/shots/`.
